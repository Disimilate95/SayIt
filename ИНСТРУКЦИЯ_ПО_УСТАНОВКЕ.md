# 📱 Инструкция по установке приложения SayIt на телефон

Готовый установочный пакет: **`SayIt.apk`** находится в корне проекта.

---

## Вариант 1. Самый простой способ (прямо на телефоне, без проводов)

1. **Скачайте файл `SayIt.apk`**:
   - Через файловый менеджер AI Studio нажмите правой кнопкой на `SayIt.apk` → **Download** (или отправьте его себе в Telegram «Избранное», WhatsApp, Google Диск или Яндекс.Диск).
2. **Откройте `SayIt.apk` на вашем Android смартфоне** (через шторку уведомлений или в приложении «Проводник» / «Мои файлы» / «Загрузки»).
3. **Нажмите «Установить»**:
   - Если телефон спросит «Разрешить установку из неизвестных источников» для Telegram/Браузера/Проводника — нажмите **«Разрешить»** (это стандартный вопрос Android для любых сторонних APK вне Google Play).
4. **Готово!** Иконка **SayIt** появится на рабочем столе телефона.

---

## Вариант 2. Быстрая установка с компьютера через кабель (1 клик)

Если вы подключили телефон к компьютеру по USB-проводу:

### Для Windows:
1. Включите на телефоне **Отладку по USB** (*Настройки -> Для разработчиков -> Отладка по USB*).
2. Подключите телефон к компьютеру кабелем и подтвердите запрос доверия на экране телефона.
3. Дважды кликните по файлу **`install_on_phone.bat`**.
4. Скрипт сам определит телефон, установит приложение и запустит его.

### Для Mac / Linux:
1. Включите **Отладку по USB** на телефоне.
2. В терминале в папке проекта запустите:
   ```bash
   ./install_on_phone.sh
   ```
